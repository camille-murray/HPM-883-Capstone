# HPM-883 Capstone Project

## Overview

This repository contains the capstone project for HPM-883. The project includes epidemiological analysis with conceptual models, directed acyclic graphs (DAGs), and comprehensive statistical analysis conducted in R.

## Project Contents

### Documentation & Deliverables
- **883 Capstone Presentation.pdf** - Final presentation slides
- **Final-Project.qmd** - Final capstone report (Quarto document)
- **Draft-Project.qmd** - Draft version of the capstone report

### Visualizations & Models
- **Conceptual Model** - Conceptual framework for the analysis
- **DAG** - Directed Acyclic Graph showing causal relationships
- **DAG-legend** - Legend and explanation of the DAG

### Configuration Files
- **.Rprofile** - R environment configuration
- **renv.lock** - R package dependency lock file
- **renv/** - R environment management directory
